# GitHub Repository Search

Vue 3 + TypeScript + Vuetify project foundation. Search and repository detail are not implemented yet.

## Stack

Vue 3 with Composition API and `<script setup>`
TypeScript in strict mode
Vuetify 3
Sass
Vitest and Vue Test Utils
ESLint

## Setup

```sh
npm install
```

### Development

```sh
npm run dev
```

### Type-check, tests, and production build

```sh
npm run type-check
npm test
npm run build
```

### Lint

```sh
npm run lint
```
